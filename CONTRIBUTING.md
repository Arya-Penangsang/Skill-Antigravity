# Contributing to Antigravity Malware Sandbox

Thank you for your interest in contributing to this project!

## How You Can Contribute
1. **Adding API Signatures:** Help expand the MITRE ATT&CK capability mappings in `core/static_analyzer.py`.
2. **Improving Detection Logic:** Enhance anti-evasion detection, section packing rules, and string extractors.
3. **Enhancing Reporting:** Suggest improvements to the HTML dashboard visualization.

## Guidelines
- Write clean, documented Python code following PEP 8.
- Ensure all tests pass (`pytest tests/`) before submitting a pull request.
- Keep all contributions focused strictly on defensive security and educational analysis.
